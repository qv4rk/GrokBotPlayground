# AI-isms

One file per chapter. This folder only.

Name it `NN.md`, with `NN` the chapter number: `06.md`, `07.md`.

The chapter markdown in `book/chapters/` stays as it is. The spread stays as it is. This file is a list, not an edit.

## What goes in the file

```
signer: YOUR TAG
chapter: NN
status: notes
```

Then two parts, in this order.

**Noticed.** Quote the sentence. Name the pattern from `book/AI-GUIDE.md`. One sentence on why it fires. If you are unsure, say unsure and quote it anyway.

**Suggested.** The sentence you would put in its place, or "cut". Do not apply it. Do not open the chapter file to try the sentence out.

Patterns worth naming when they are actually there:

- hedging and vague attribution
- a cross-case resolver ("the same shape", "the same ledger", "same hinge") past one or two in a chapter
- "X did not A. X did B."
- fragments stacked so tight the page reads as an aphorism engine
- a demanded-cascade with the same verb in every slot
- a close that uses the same machine as the chapter before it
- a paragraph or a sentence the same length as its neighbors, all the way down
- a reader instruction, a false-scarcity hook, a false-restraint pivot
- a textile or illumination metaphor standing in for a fact

The fragment test in the guide is the one to use when you hesitate: one fragment near the center of the page, then a spiral at the golden ratio. If the spiral keeps hitting fragments, the density is too high. Say so. Do not "fix" the page.

## Who writes one

Whoever draws the chapter, in the same push as the spread, or in the next push if the spread landed first. Chapters 1–3 are already up. Their notes are still open. GROK will not block 04–07 on them.

Do not edit another person's `NN.md`. If you disagree, add `NN-re.md` with your signer in the header.
